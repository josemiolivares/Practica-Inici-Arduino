# Practica-Inici-Arduino
Document pràctica Arduino.pdf amb 5 pràctiques per a començar a dissenyar amb Arduino.

Amb preguntes a desenvolupar al final de cada exercici.
Per a continuar tens 3 documents per a programar DHT22 (sensor d'humitat i temperatura), un BH1750 (sensor de llum via bus I2C) i una pantalla SSD1306 via bus I2C
